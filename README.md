# 블로그 릴스 메이커

네이버 블로그 글 링크 하나를 넣으면 PC에서 릴스/쇼츠 영상을 만들어 주는 웹앱입니다.

- 출력: 9:16 세로, 1080×1920, 30fps, MP4(H.264 + AAC)
- 처리 순서: 본문·사진 추출 → 한국어 대본·자막 작성 → 무료 AI 음성 → 사진 움직임 합성
- 비용: 기본 설정은 **0원**입니다. 외부 서버 없이 내 PC에서 돌아가며, 유료 API는 직접 승인했을 때만 호출합니다.

## 실행 방법

### Windows
1. [Python 3.10 이상](https://www.python.org/downloads/)을 설치합니다. 설치할 때 "Add to PATH"를 체크하세요.
2. `run_windows.bat`를 더블클릭합니다. 영상 엔진(FFmpeg)은 패키지에 들어 있어 따로 설치할 필요가 없습니다.
3. 준비가 끝나면 브라우저에 `http://127.0.0.1:8765`가 열립니다. 검은 창은 앱을 쓰는 동안 닫지 마세요.
   - 브라우저 자동화는 PC에 기본 설치된 Edge를 씁니다. 추가 다운로드는 없습니다.

### macOS / Linux
```bash
./run_mac_linux.sh        # 처음 한 번은 필요한 패키지를 자동으로 설치합니다
```

### 사용 순서
1. 블로그 글 주소를 넣고 **글·사진 가져오기**를 누릅니다.
2. 추출 결과를 확인합니다: 제목, 본문 성공 여부, 사진 발견/다운로드 개수, 읽지 못한 부분과 원인.
3. **사진** 칸에서 사진을 눌러 고칩니다(원본은 그대로 보관).
   - 회전·좌우 반전, 밝기·대비·채도 조절
   - 사진을 클릭해 **영상에서 보일 중심**을 지정합니다. 밝은 테두리 영역이 실제로 화면에 나오는 부분입니다.
   - **+ 내 사진 추가**로 PC의 사진을 넣을 수 있고, 사진의 **✕** 버튼으로 영상에서 뺄 수 있습니다(PC의 원본 파일은 지우지 않음).
4. **대본·장면** 칸 위쪽에서 **시공 주제**(자동 감지 또는 직접 선택)와 **훅 스타일**(공감 질문형/경고형/반전·궁금증형/결과 강조형)을 고르고 **대본 다시 만들기(무료)**를 누르면, 레퍼런스처럼 한 사람이 이어 말하듯 대본을 새로 씁니다.
   - 순서: 훅 → 왜 해야 하는지(안전·위험) → 실제 현장 상황 → 그래서 이번 현장은 → 먼저/그다음/이제 ~해 주면 끝입니다 → 혹할 포인트 → 이렇게 결과 → 상담
   - 블로그의 **본문만** 읽습니다. 소제목·인용구 소제목·표·광고/협찬 문구·연락처·해시태그는 빼고, 현장 내용은 블로그 문장만 씁니다.
   - 주제별 문구는 `reels_app/hooks.py`에서 고치거나 추가할 수 있습니다(볼라드, 마루, 타일, 방수, 누수, 곰팡이, 창호, 도배, 욕실, 실리콘, 문, 주방, 도장, 난간, 전기 등).
5. 장면별 대본·상단 문구·강조 단어를 고치고, **사진 고르기**로 장면에 넣을 사진을 클릭해 고른 뒤 **수정 저장**을 누릅니다.
6. **음성 배속**을 슬라이더(0.7~1.6배)나 빠른 버튼(0.9x~1.5x)으로 고르고, **▶ 미리 듣기**로 첫 문장을 들어 봅니다. 고른 배속은 다음 실행 때도 유지됩니다.
7. **영상 만들기**를 누르면 진행률이 표시되고, 끝나면 화면에서 바로 재생하거나 내려받을 수 있습니다.
   - 무료 대본은 고른 배속에 맞춰 문장 수가 자동 조정되어 40~60초 안에 들어옵니다.
   - 직접 고친 대본이 60초를 넘으면 음성을 조금 더 빠르게 맞추고, 화면에 그 사실을 알려 줍니다.

명령줄로도 실행할 수 있습니다: `python -m reels_app "https://blog.naver.com/아이디/글번호"`

## 수동 편집 (무료 · AI 재호출 없음)
영상을 만들면 아래에 **수동 편집** 칸이 열립니다.
- **자동으로 만든 문구도 편집**: 상단 문구·자막·엔딩 문구는 영상에 박지 않고 편집 가능한 문구로 만듭니다. 목록의 '자동 자막', '자동 상단·엔딩 문구'를 누르면 **전체 위치·크기·색을 한 번에** 바꾸고, '하나씩'을 펼치면 문구 하나의 내용·강조 단어·위치를 고칠 수 있습니다. 자막 하나를 끌면 자막 전체가 함께 움직입니다(체크 해제 시 하나만). 고친 내용은 미리보기에 바로 보이고, 정한 전체 위치·크기는 영상을 다시 만들어도 유지됩니다.
- **사진**: 본문 사진은 개수와 상관없이 순서대로 **한 장씩, 한 번씩만** 나옵니다(사진 수에 맞춰 시간을 고르게 나눔).
- **문구 편집**: '+ 문구 추가'나 템플릿으로 텍스트 박스를 넣고, 글자 크기·색·배경(색·불투명도)·그림자·외곽선·위치(끌어서 이동)·시작/끝 시간을 정합니다. 미리보기는 고칠 때마다 바로 바뀌고, **최종 영상에 적용**을 누르면 문구만 FFmpeg로 다시 합성합니다(음성·대본은 다시 만들지 않음). 자주 쓰는 문구는 **템플릿으로 저장**(`output/text_templates.json`).
- **썸네일**: 1초 간격 타임라인에서 장면을 고르거나 **자동 추천 3개**(무료 이미지 분석: 선명도·대비·채도·밝기 + 결과/훅 장면 가산, AI API 미사용) 중에서 고릅니다. 썸네일 문구의 위치·크기·색·배경을 조절하고 PNG/JPG로 저장합니다. 기본은 자막·라벨이 없는 깨끗한 화면이고, 필요하면 '자막·라벨이 들어간 화면 그대로 쓰기'를 켭니다.
- **안전 영역**: 인스타 릴스/유튜브 쇼츠에서 앱 화면(상단 메뉴·하단 설명·오른쪽 버튼)에 가려질 수 있는 곳을 빨간 영역으로 표시하고, 문구가 그 밖으로 나가면 경고합니다(대략값). 썸네일은 프로필 격자(3:4) 잘림도 표시할 수 있습니다.
- **최종본 미리보기** 탭에서 완성 영상과 썸네일을 확인하고, 아래에서 **MP4 · 썸네일 · 자막(SRT)**을 내려받습니다.

## 음성·보조 영상
- **목소리 선택**: 영상 만들기 칸에서 엔진(Edge 무료 / Azure F0 무료 / PC 내장)과 남성·여성 목소리를 고르고, 배속·음량을 조절해 **▶ 미리 듣기**로 확인합니다. **기본으로 저장**을 누르면 다음에도 그 설정으로 시작합니다.
- **Azure 음성**: ⚙ API 키 설정에 Azure Speech 키·지역을 넣습니다(F0 무료 리소스 권장). 이번 달 사용량 막대가 표시되고, 무료 한도 80%에서 경고합니다.
- **보조 영상**: '보조 영상' 칸에서 Pexels·Pixabay(무료 키 필요)를 검색해 고른 영상만 추가합니다. Mixkit은 사이트에서 직접 받은 파일을 출처 주소와 함께 등록합니다. 장면별 '보조 영상'에서 고르거나, 자동 사용을 켜면 사진이 부족한 설명 장면에만 들어갑니다.
- 라이선스·API 조건 정리: [docs/FREE_SOURCES.md](docs/FREE_SOURCES.md)

## 결과물 위치
- `extracted_images/<블로그ID>_<글번호>/`: 본문 사진 원본(순서대로 001, 002…)과 `post.json`(제목·본문·사진 설명)
- `output/<작업ID>/reel.mp4`: 완성 영상. 같은 폴더에 `subtitles.srt`(자막), `narration.wav`(내레이션), `job.json`(작업 기록·비용)

## 비용 구조
| 단계 | 방식 | 비용 |
|---|---|---|
| 글·사진 추출 | Playwright(브라우저 자동화) | 무료 |
| 대본·자막 | 규칙 기반(본문 문장 선택 + 레퍼런스 말투로 다듬기) | 무료, AI 호출 없음 |
| 음성 | Edge 무료 한국어 음성(SunHi) → 실패하면 PC 내장 음성 | 무료, API 키 불필요 |
| 영상 합성 | Python(Pillow) + FFmpeg | 무료 |
| (선택) AI 대본 | Claude Haiku 5.5, 1편당 1회 호출, 사진은 보내지 않음 | 예상 약 $0.001~0.002(약 2~3원) |

- AI 대본은 화면의 **AI로 다시 쓰기(유료)** 버튼을 눌러 예상 토큰·비용을 확인하고 승인했을 때만 실행됩니다.
- 실제 사용량은 "이번 영상 비용" 칸과 `job.json`에 기록됩니다.
- AI를 쓰려면 화면의 **⚙ API 키 설정**에서 **Claude API 키**를 넣고 저장하세요(console.anthropic.com에서 키 발급·크레딧 충전 필요). 키는 이 PC의 `settings.local.json`에만 저장됩니다.

## 설정 (`settings.json`, 선택)
프로젝트 폴더에 `settings.json`을 만들면 기본값을 바꿀 수 있습니다. 전체 항목은 `reels_app/config.py`에 있습니다.
```json
{
  "brand_name": "가온집수리",
  "cta_text": "전문가에게 상담받아 보세요.",
  "cta_highlight": "상담받아",
  "theme": "dark_blue",
  "tts_voice": "ko-KR-SunHiNeural",
  "tts_speed": 1.1,
  "target_seconds": 48
}
```
- 로고: `reels_app/assets/logo.png` (레퍼런스 엔딩에서 추출한 가온 로고)
- 배경음악: `reels_app/assets/bgm.mp3`를 넣으면 작게 깔립니다. 저작권 없는 음원만 쓰세요.
- 스타일 근거: [docs/STYLE_GUIDE.md](docs/STYLE_GUIDE.md)

## 지키는 원칙
- 공개 글만 읽습니다. 로그인·비공개·서로이웃·삭제·접근 제한 글은 우회하지 않고 원인을 그대로 보고합니다.
- 프로필 사진, 스티커, 이모티콘, 링크 미리보기, 지도, 아이콘 크기 이미지는 본문 사진에서 제외합니다.
- 추출에 실패하면 성공으로 표시하지 않습니다. 실패한 사진은 하나씩 오류 원인을 남깁니다.

## 문제 해결
- **"페이지 접속 실패: net::ERR_TUNNEL_CONNECTION_FAILED / ERR_NAME_NOT_RESOLVED"**: 이 PC나 네트워크가 `blog.naver.com`, `m.blog.naver.com`, `*.pstatic.net` 접속을 막고 있습니다(회사 방화벽, 클라우드 샌드박스 등).
- **음성이 기계음**: Edge 음성 서버(`speech.platform.bing.com`)에 연결되지 않아 오프라인 음성으로 바뀐 경우입니다. 인터넷 연결을 확인하세요.
- **브라우저 실행 실패**: `python -m playwright install chromium`을 실행하거나, `settings.json`의 `"browser_executable"`에 크롬 경로를 넣으세요.
