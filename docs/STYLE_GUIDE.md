# 영상 스타일 가이드 (레퍼런스 분석)

분석 대상: 사용자가 올린 레퍼런스 쇼츠 2편. 세 번째로 올린 파일은 두 번째 파일과 내용이 같았습니다(해시 동일).

| | 레퍼런스 A: 마루 부분 보수 | 레퍼런스 B: 매립식 안전기둥 |
|---|---|---|
| 규격 | 1080×1920, 30fps, H.264/AAC | 같음 |
| 길이 | 59.9초 | 46.7초 |
| 배경 | 어두운 회색 그라데이션 `#1E1F21 → #0F1012` | 검정 `#040404` |
| 강조색 | 파랑 `#507AFF` | 연두 `#7EF104` |
| 오프닝 제목 | 상단 흰색 라벨 | 노란색 `#F6C10A` 브랜드명 "가온집수리" |

## 화면 구성 (1080×1920 기준)
- **상단 라벨** (중심 y≈360): 장면을 요약하는 12자 안팎 문구. 예: "발에 걸리는 파손된 바닥재", "전용 접착제 균일 도포"
- **사진 밴드** (중심 y≈980): 1장이면 가로를 꽉 채우고, 2장(전/후, 과정)이면 좌우로 나란히 놓습니다. 같은 사진을 여러 문장 동안 쓸 때는 확대 부분을 바꿔 보여 줍니다.
- **자막** (y≈1450/1555): 2줄, 큰 굵은 글씨, 흰색과 검은 외곽선. 문장을 7~10자 단위로 끊고, 핵심 단어 하나만 강조색으로 칠합니다.
- **엔딩**: 상단 "OO 전문 상담 / OO 시공 문의", 가운데 검은 패널에 로고, 하단 CTA "전문가에게 **상담받아** 보세요."

## 대본 구조와 말투
1. 공감 훅 질문: "멀쩡해 보이던 우리 집 바닥, 파손된 거 보신 적 있으시죠?"
2. 문제·위험: "단순히 미관상 문제만 있는 게 아니라 곰팡이가 생기거나…"
3. 전환: "그래서 오늘은 딱 필요한 …"
4. 작업 과정 2~5문장: "기존 마루를 깔끔하게 정리한 뒤에, 전용 접착제를 … 고정해주면 끝입니다."
5. 결과: "이렇게 부분 보수만으로도 새 …"
6. CTA: "전문가에게 상담받아 보세요."

- 친근한 존댓말(~죠?, ~는데요, ~입니다)을 씁니다.
- 문장은 짧게, 과장 없이 씁니다.

코드에서 이 값들은 `reels_app/config.py`(색·문구)와 `reels_app/render.py`(배치)에 들어 있습니다. 테마는 `settings.json`의 `"theme": "dark_blue" | "black_green"`으로 바꿉니다.
